# Completed preliminary experiments — 5 November 2026

This archived evidence contains the 64-image/configuration pilot, 2,000-image/configuration uniform solver screen and separate 2,000-image/configuration schedule validation. All reported metrics and timings are measured pretrained JiT outputs. The two larger final evaluations and intermediate prediction captures have not run. Screening results do not establish the proposal’s quality tolerance.

`figures/` contains PNG, SVG and PDF figures plus a combined measurement CSV. Each run directory preserves its manifest, paired seeds/labels, timing repetitions, metrics, summary and paired image grid. Root JSON files preserve the audit, selection and pending status. Source revision/diffs and local paths in archived manifests describe the original execution environment and are retained as provenance.

The full PNG sample corpus and checkpoint remain outside Git under `/mnt/research/jit-sampling/`. The presentation is at `../../jit-sampling-efficiency/presentation.pptx`; the full narrative report is at `../../experiment-results.md`.
